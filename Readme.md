# 5G Modem SIM7080G - S32K3XX Driver

This is a driver created to provide 5G connectivity to Automotive Microcontroller S32K344 and all the other members of the S32K3XX family.
The main objective with this driver is to make it easier to migrate for other platforms with a layer approach of implemnetation regarding
the different functionalities provided with SIM7080G.
